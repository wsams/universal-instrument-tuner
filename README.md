# Universal Instrument Tuner

A tuner for any instrument, ready in the browser.

<p align="center">
  <a href="https://wsams.github.io/universal-instrument-tuner/">
    <img alt="Tune now" src="web/tune-now.png" width="320">
  </a>
</p>

Play a note. You'll see the pitch and how close you are, and the needle stays put while you bring it in.

It works for strings, winds, brass, voice, and anything else that holds a pitch.

Concert pitch starts at A440. Move that if you tune somewhere else, choose how exact "in tune" needs to be, and settle the needle if you want it even steadier. Hear plays the note you're aiming for, so you can match it by ear.

Nothing to install. Nothing is recorded.
